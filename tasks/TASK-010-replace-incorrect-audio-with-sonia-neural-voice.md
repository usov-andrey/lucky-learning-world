# TASK-010: Replace Incorrect Audio with Sonia Neural Voice

## 1. Goal and context

The v1.3.0 `or-saying-er` lesson was released with audio generated by the local default system voice. The voice was not explicitly English and produced unacceptable, incorrect pronunciation. The user approved the British female neural sample `en-GB-SoniaNeural` and requested that Sonia always be used for Lucky Learning World going forward.

## 2. Acceptance criteria

- [x] **AC-29**: All 18 word tracks and all 18 definition tracks for `or-saying-er` are regenerated as non-empty MP3 files with the user-approved `en-GB-SoniaNeural` voice at rate `-15%`; the catalog references only these files and none of the incorrect WAV tracks remain.
- [x] **AC-30**: Project rules and audio provenance permanently identify `en-GB-SoniaNeural` as the required Lucky Learning World spelling voice, prohibit silent fallback to a system voice, and require an approved sample before any future voice change is released.
- [x] **AC-31**: Automated tests verify the Sonia configuration, all audio paths and files, and the absence of legacy WAV tracks; the full suite and coverage gate pass before release `v1.3.2` is committed and deployed.

## 3. Test coverage

- `tests/spelling-lesson-catalog.test.mjs` — MP3 paths, non-empty assets, and no legacy WAV files.
- `tests/coverage.test.mjs` — persistent Sonia voice configuration and no system-voice fallback.
